==================================================================================================================
- ASTAP, the Astrometric STAcking Program by Han Kleijn (https://www.hnsky.org/astap.htm). JustComets can run an
  ASTAP installation chosen by the user as a fallback plate solver. ASTAP and its star databases are not part of
  JustComets and are distributed by their author under their own terms.
- INDI Library (https://indilib.org): the INDI server and its device drivers. JustComets has code that can
  connect to an INDI server over the network and, on Linux and macOS, start and stop one that the user has
  installed. INDI and its drivers are not part of JustComets, contain no JustComets code and are distributed by
  their authors under their own terms (the INDI Library under the GNU LGPL version 2.1 or later; individual drivers
  under their own licenses). JustComets contains no INDI code: it speaks the published INDI protocol with its own software.
- RC Astro's stand-alone tools (https://www.rc-astro.com): the program "rc-astro" with BlurXTerminator,
  NoiseXTerminator and StarXTerminator. The Image Processing tab can run an rc-astro installation that the user
  has installed and licensed, as a separate program, as RC Astro's integration guide describes. The program, its
  neural network models and its icons are not part of JustComets, are never distributed with it, and are licensed
  to the user by RC Astro, LLC under its own license agreement. The product names are trademarks of their owner and
  are used only to say which program is run.
